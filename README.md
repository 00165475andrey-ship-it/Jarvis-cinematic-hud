# J.A.R.V.I.S. Desktop

Самостоятельное настольное приложение с плавающими системными виджетами и панелями управления для Windows.

- Сборка: Windows x64.
- Windows 10/11 x64 — основные целевые системы; Windows 7 SP1 x64 — экспериментальная дополнительная цель, требующая проверки на реальном ПК.
- Интерфейс приложения: русский.

## Быстрый запуск

1. Откройте [Actions](../../actions) в этом репозитории.
2. Выберите последний успешный запуск **Build Windows app**.
3. Внизу страницы откройте раздел **Artifacts** и скачайте **JARVIS-Desktop-Windows-x64**.
4. Для Windows 7 SP1 x64 используйте отдельный успешный запуск **Build Windows 7 compatible app** и артефакт **JARVIS-Desktop-Windows-7-x64**.
5. Распакуйте ZIP-архив в отдельную папку.
6. Запустите `JarvisDesktop.exe`.

При первом запуске Windows может показать системное предупреждение для приложения, скачанного из интернета. Запускайте файл только если скачали его из Actions этого репозитория и доверяете исходному коду.

## Первое использование

1. Запустите приложение. Откроется главное окно J.A.R.V.I.S.
2. На странице «Обзор» отображается состояние системы.
3. Кнопка **«ПОКАЗАТЬ / СКРЫТЬ ВИДЖЕТЫ»** включает или скрывает все плавающие показатели.
4. В разделе «Внешний вид» настройте оформление и общую прозрачность виджетов.
5. Там же выберите один из четырёх визуальных стилей: Classic, Heavy Metal, Liquid Glass или Pencil Sketch. Для каждого стиля отдельно сохраняются акцент, выразительность, звуковые эффекты, громкость и характер анимации; настройки находятся в `jarvis.ini`.
6. В разделе «Поведение» выберите нужные модули и настройте параметры каждого модуля.
7. Кнопка «Открыть голосовые макросы» запускает отдельную панель голосового управления.

Положение окон, параметры и настройки виджетов сохраняются в файле `jarvis.ini` рядом с EXE. Не удаляйте этот файл, если хотите сохранить настройки. Для переноса конфигурации на другой компьютер скопируйте `jarvis.ini` вместе с приложением.

## Плавающие виджеты

Программа может показывать отдельные окна с системными показателями:

- загрузка CPU;
- использование RAM;
- свободное место на диске C:;
- входящая и исходящая скорость сети;
- время работы Windows;
- заряд батареи (если устройство её предоставляет);
- количество запущенных процессов;
- часы.

### Управление мышью

- **Перетаскивание:** зажмите левую кнопку мыши на виджете и переместите его.
- **Контекстное меню:** нажмите правой кнопкой мыши по виджету.
- **Закрепить поверх окон:** в контекстном меню выберите этот пункт. Повторный выбор отключает закрепление.
- **Скрыть показатель:** выберите этот пункт, чтобы скрыть только выбранный виджет. Остальные продолжат работать.
- **Сквозные клики:** соответствующий пункт контекстного меню переключает режим, в котором щелчки мыши проходят сквозь виджеты к окнам под ними. Чтобы снова открыть контекстное меню, сначала отключите сквозные клики горячей клавишей.

### Горячие клавиши

| Сочетание | Действие |
|---|---|
| **Ctrl + Alt + J** | Включить или отключить сквозные клики через виджеты. Нажмите сочетание повторно, чтобы переключить режим обратно. |
| **Ctrl + Alt + K** | Показать все индивидуально скрытые виджеты и восстановить их отображение. |

Горячие клавиши глобальные: они работают, пока приложение запущено, даже если его главное окно не находится на переднем плане. Если сочетание перехватывается другой программой, закройте её или измените конфликтующую комбинацию в той программе.

## Панели модулей

В приложении доступны шесть системных модулей и отдельная панель голосовых макросов:

1. **Режимы системы** — просмотр и переключение плана электропитания Windows.
2. **Менеджер процессов** — просмотр, поиск и сортировка процессов; завершение выбранного процесса с защитой критических системных процессов.
3. **Управление сетью** — просмотр сетевых адаптеров и их состояния, статистики и быстрый переход к системным сетевым настройкам.
4. **Диагностика Windows** — системная сводка и запуск встроенных средств диагностики.
5. **Сценарии автоматизации** — запуск предустановленных и пользовательского сценариев с доступными действиями.
6. **Журнал активности** — просмотр, поиск и копирование записей журнала.
7. **Голосовые макросы** — локальное распознавание русской речи через Vosk и точное сопоставление произнесённой фразы с пользовательским макросом.

Для настройки панели откройте главное окно → «Поведение» → выберите нужный модуль → «Настроить». Для каждой панели доступны индивидуальные параметры оформления: тема, размер текста, прозрачность и плотность. Общий визуальный стиль приложения выбирается отдельно в разделе «Внешний вид» и применяется к главному окну, плавающим HUD-виджетам и панелям модулей.

### Характеры визуальных стилей

- **Classic:** плавное появление и короткие электронные сигналы.
- **Heavy Metal:** более тяжёлая вертикальная анимация и синтезированный металлический скрежет/щелчок при закреплении HUD-виджета; открытие панели сопровождается механическим звуком.
- **Liquid Glass:** мягкое проявление и короткий стеклянный тональный эффект.
- **Pencil Sketch:** короткая боковая анимация и шуршащий звук, имитирующий штрих карандаша.

В разделе «Внешний вид» для выбранного стиля можно отдельно включить или отключить звук, задать громкость и выбрать интенсивность анимации. Звуки генерируются приложением на лету, внешние аудиофайлы не нужны. Звук воспроизводится при действиях с HUD (закрепление, показ/скрытие) и при открытии панели модуля.

## Голосовые макросы и Vosk

В ZIP-пакет автоматически добавляются официальный Vosk Runtime для Windows x64, его DLL-зависимости и русская офлайн-модель `vosk-model-small-ru-0.22`. Скрипт упаковки проверяет наличие ключевых файлов модели. После распаковки интернет для распознавания не требуется.

1. Откройте главное окно → «Поведение» → **«Открыть голосовые макросы»**.
2. Введите точную фразу, например `открой YouTube`.
3. В поле цели укажите сайт с `https://` или путь к приложению/папке.
4. Нажмите «Добавить макрос».
5. Выберите режим прослушивания:
   - **Постоянное прослушивание** — распознавание работает, пока нажата кнопка «Включить микрофон».
   - **Push-to-Talk** — распознавание принимает речь только пока удерживается назначенная клавиша. По умолчанию это **F7**.
6. Для Push-to-Talk можно выбрать F6–F12, Пробел, Caps Lock или правый Ctrl. Настройки режима и клавиши сохраняются в `jarvis-voice-settings.ini` рядом с EXE.
7. Нажмите «Включить микрофон». В режиме Push-to-Talk удерживайте выбранную клавишу во время речи; отпустите её, чтобы завершить фразу. Для полного выключения нажмите «Выключить».

Vosk показывает промежуточный текст распознавания, но макрос запускается только после завершения фразы (когда движок определил паузу). В панели можно выбрать входной микрофон из устройств Windows, настроить чувствительность (0–100) и минимальную среднюю уверенность распознанных слов (0–100%). Выбранное устройство сохраняется в `jarvis-voice-settings.ini`; после смены микрофона во время работы перезапустите распознавание. Аудио проходит через удаление постоянной составляющей сигнала и адаптивный мягкий шумовой порог, который оценивает уровень тихого фона и ослабляет его без жёсткого обнуления всех тихих отсчётов. Для проверки уверенности приложение запрашивает у Vosk оценки слов; финальная команда с оценкой ниже порога отклоняется. Перед передачей аудио применяется программный шумовой порог для ослабления тихого фонового шума. Слишком высокий порог чувствительности может обрезать тихую речь, а слишком высокий порог уверенности — отклонять правильно распознанные фразы; подбирайте значения под свой микрофон. Сопоставление команд строгое: учитываются слова и внутренние пробелы; регистр и крайние пробелы не учитываются. Нечёткого поиска и подмены похожих фраз нет. Действие выполняется только при точном совпадении финального распознанного текста с сохранённой фразой. Повторяющиеся фразы запрещены. Макросы сохраняются в `jarvis-voice-commands.txt` рядом с EXE. Допускается до 100 макросов.

Распознавание выполняется локально. Требуются микрофон и разрешение Windows на его использование. Панель показывает состояние прослушивания и Push-to-Talk. В режиме Push-to-Talk аудиоданные передаются распознавателю только при удержании выбранной клавиши; при этом сам аудиопоток устройства остаётся открытым, пока голосовое распознавание включено. Микрофон не включается автоматически при запуске приложения.

**Совместимость:** текущая программа использует Win32 API, а пакет Vosk содержит только официальный Windows x64 runtime. Windows 10/11 x64 — основные целевые системы. Windows 7 SP1 x64 — экспериментальная цель: одной настройки минимальной версии Windows в EXE недостаточно, чтобы гарантировать совместимость DLL и системных зависимостей; требуется отдельная проверка на Windows 7. Linux, macOS, Windows 32-bit и ARM64 текущей версией приложения не поддерживаются. Для этих платформ понадобятся отдельные сборки приложения и соответствующие Vosk-библиотеки.

## Файлы приложения

- `JarvisDesktop.exe` — исполняемый файл приложения.
- `libvosk.dll` и остальные DLL — локальный движок распознавания речи.
- `models/` — русская модель Vosk.
- `jarvis-voice-commands.txt` — пользовательские голосовые макросы (создаётся после первого сохранения).
- `jarvis.ini` — локальные настройки, создаётся рядом с EXE.
- `jarvis.log` — журнал событий, создаётся рядом с EXE по мере работы приложения.

Рекомендуется хранить EXE и создаваемые рядом файлы в папке, в которой у пользователя есть права на запись.

## Ограничения

Универсальный FPS-счётчик для всех игр, загрузка/температура GPU, температуры CPU, частоты и показатели отдельных дисков пока не реализованы. Для FPS обычно нужен отдельный источник данных (например, PresentMon или поддерживаемый игровой API); обычное Win32-приложение не может достоверно получить FPS любой игры само по себе.

Оверлей может быть перекрыт некоторыми играми в эксклюзивном полноэкранном режиме. Для таких игр попробуйте оконный режим или режим без рамки.

## Сборка вручную

Нужны CMake и Visual Studio 2022 с компонентом **Desktop development with C++**:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

Чтобы вручную подготовить файлы Vosk в папку пакета (после сборки EXE; требуется 64-битная Windows):

```powershell
./tools/prepare-vosk.ps1 -Destination package
```

Исходный Windhawk-мод сохранён отдельно в `src/JARVIS_Cinematic_HUD.wh.cpp`.


## Совместимость платформ

Текущая версия J.A.R.V.I.S. Desktop — приложение для Windows x64. Windows 10/11 — основная цель; Windows 7 SP1 x64 собирается отдельным экспериментальным workflow. Linux и macOS пока не поддерживаются самим приложением: интерфейс, системные панели и захват микрофона используют Windows API. Windows x86 также не поддерживается текущим комплектом Vosk.

Workflow **Platform compatibility checks** автоматически проверяет, что Linux/macOS и Windows x86 получают понятное сообщение о неподдерживаемой платформе. Это проверка защитных ограничений, а не кроссплатформенная сборка. Подробный план переноса: [docs/PLATFORM_PORTING.md](docs/PLATFORM_PORTING.md).
