# J.A.R.V.I.S. Desktop

Самостоятельное настольное приложение для Windows 10/11 x64.

## Плавающие виджеты
Программа создаёт отдельные прозрачные окна поверх обычных окон Windows. Каждый показатель можно перетащить левой кнопкой мыши в любое место рабочего стола. Положение сохраняется в `jarvis.ini`. Виджеты остаются поверх обычных окон, пока включены; некоторые игры в эксклюзивном полноэкранном режиме могут перекрывать сторонние оверлеи.

Доступные показатели:
- загрузка CPU;
- использование RAM;
- свободное место на диске C:;
- входящая и исходящая скорость сети;
- время работы Windows;
- заряд батареи (если устройство её предоставляет);
- количество запущенных процессов;
- часы.

Прозрачность виджетов регулируется в разделе «Внешний вид». Кнопка на главном экране скрывает или показывает все виджеты. Положение и настройки сохраняются локально.

## Ограничения
Универсальный FPS-счётчик для всех игр, загрузка/температура GPU, температуры CPU, частоты и показатели отдельных дисков пока не реализованы. Для FPS в играх обычно нужен отдельный источник данных (например, PresentMon/поддерживаемый игровой API); обычное Win32-приложение не может достоверно получить FPS любой игры само по себе.

## Скачать
Откройте вкладку Actions репозитория, выберите последний успешный запуск Build Windows app и скачайте артефакт `JARVIS-Desktop-Windows-x64`.

## Сборка вручную
Нужны CMake и Visual Studio 2022 с компонентом Desktop development with C++:
```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

Исходный Windhawk-мод сохранён отдельно в `src/JARVIS_Cinematic_HUD.wh.cpp`.
